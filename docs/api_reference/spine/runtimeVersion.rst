===================================
spine.runtimeVersion
===================================

| **Type:** ``string``
| **See also:** :doc:`index`, :doc:`version`

Overview:
.........

The Spine runtime the plugin is built on: ``"4.2"`` or ``"4.3"``. Export your skeletons with the same Spine editor
version.

Example:
--------

.. code-block:: lua

   print("Spine runtime", spine.runtimeVersion)
